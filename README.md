AIR Blend
=========

**AIR Blend** is a free and open source 3D creation suite based on Blender 3.6.
It supports the entirety of the 3D pipeline — modeling, rigging, animation, simulation, rendering, compositing, motion tracking and video editing.

This is a rebranded fork focused on simplicity and a lightweight design.
